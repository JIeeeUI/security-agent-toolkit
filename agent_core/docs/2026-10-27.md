# [Mission 조건문]

**날짜:** 2026-10-27  
**대상 파일:** `assignment_02_f1.py`, `assignment_02_f2.py`

---

## 🌟 STAR 학습 정리

### 1. Situation (상황)
- 보안 점검 결과 상태값(`SUCCESS`, `FAIL`, `OK`)이나 점검 횟수(`count`)에 따라 서로 다른 후속 조치(예: "점검 대상", "확인 필요", "계속 진행", "기록 유지", "정상") 메시지를 분기하여 출력해야 하는 상황이었다.

### 2. Task (목표)
- 파이썬의 `if`와 `else` 기본 조건문 구조를 익히고, 비교 연산자(`==`, `>=`)를 올바르게 사용하여 상황별 분기 처리 코드를 완성하는 것을 목표로 했다.

### 3. Action (한 일)
- **`if`와 `else` 출력 및 `==` 연산자 복습**:
  - `assignment_02_f1.py`:
    - `result` 변수에 `"SUCCESS"`와 `"FAIL"` 값을 각각 할당하고, `if result == "FAIL":` 조건을 걸어 `==` 연산자로 문자열이 일치하는지 비교했다.
    - 조건이 참일 때 `print("확인 필요")` 또는 `print("점검 대상")`, 거짓일 때 `else` 블록에서 `print("계속 진행")`이 출력되도록 작성했다.
  - `assignment_02_f2.py`:
    - 수치 비교 연산자(`count >= 3`)를 이용해 임계치에 따른 분기를 출력했다.
    - `result == "OK"` 조건을 통해 정상/실패 상태를 출력하는 분기를 실습했다.

### 4. Result (확인한 결과 및 새로 알게 된 점)
- **확인한 결과**:
  - `result` 값이 `"SUCCESS"`일 때는 조건이 거짓이 되어 `else` 구문의 `"계속 진행"`이 출력되는 것을 확인했다.
  - `result` 값이 `"FAIL"`일 때는 조건문이 참이 되어 `"확인 필요"`(또는 `"점검 대상"`)가 정확히 출력되는 실행 결과를 확인하고 배웠다.
- **새로 알게 된 점 & 다짐**:
  - `if`와 `else`, 그리고 같음을 비교하는 `==` 연산자를 쓰는 법을 조금 더 확실하게 알게 되었다.
  - 조건문 기초를 탄탄히 다진 만큼, 앞으로 더 다양하고 복잡한 조건(예: 다중 조건문 `elif`, 논리 연산자 등)으로 응용해서 써보고 싶다.
