## 오늘 배운 내용 / 새로 쓴 문법 및 명령
- `for ... in ...`: 리스트의 요소를 하나씩 꺼내어 반복 처리하는 문법
- `range(stop)`, `range(start, stop)`: 정해진 횟수나 범위만큼 숫자를 생성하여 반복하는 함수
- `requests`: 외부 HTTP 요청 라이브러리 설치 및 버전 확인

### 2. 정해진 횟수 반복 (`assignment_03_f2.py`)
- `range(1, 4)`: 1부터 3까지 반복 (4는 미포함)
- `range(5)`: 0부터 4까지 5회 반복하며 `f"{number + 1}번째 점검"` 형식으로 보안 점검 메시지 출력

---

## 찾아보고 알게 된 것
- `range(start, stop)`에서 `stop` 값은 범위에 포함되지 않고 `stop - 1`까지만 실행된다는 점.
  - 예: `range(1, 4)`는 1, 2, 3까지만 출력됨.
- `range(n)`에 1을 더해 1번부터 시작하는 사용자 친화적 번호(점검 회차 등)를 표시할 수 있음.

---

## 막힌 것 및 해결
- **이슈**: `range(1, 4)` 실행 시 4가 출력되지 않음.
- **원인 및 해결**: 파이썬의 슬라이싱과 범위 지정 규칙에 따라 끝 번호(stop) 직전까지만 반복됨을 확인하고 이해함.
